# the-quest-for-the-seven-scrolls
a pixel game like undertale. Get all seven scrolls to win

## Deployment

This project uses [GitHub Pages](https://pages.github.com/) for static hosting. To publish:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Build and deploy:
   ```bash
   npm run deploy
   ```

The `homepage` field in `package.json` is already configured for the repository URL, and the `gh-pages` package takes care of creating a `gh-pages` branch containing the production build.
